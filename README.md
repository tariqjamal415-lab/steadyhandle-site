# steadyhandle-site

Marketing site for **SteadyHandle** — Your calls, handled. 24/7.

The site is static HTML served by GitHub Pages from the `main` branch, root (`/`):

- `index.html` — the marketing page
- `privacy/index.html` — Privacy Policy (`/privacy/`)
- `terms/index.html` — Terms of Service (`/terms/`)
- `assets/legal.css` — shared styles for the legal pages
- `favicon.svg`, `robots.txt`, `sitemap.xml`

- Live: https://tariqjamal415-lab.github.io/steadyhandle-site/
- Custom domain: `steadyhandle.com` (configured via the `CNAME` file; DNS is managed separately at the registrar)
